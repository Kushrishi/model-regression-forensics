# Exp009 portable pilot evidence

This directory contains lightweight development-pilot evidence needed to
continue Experiment 009 on another machine.

Included are the three clean run summaries and prediction-ID artifacts, the
completed corruption-dose summaries, and the recorded outcome of the first
frozen nuisance-selection rule.

Model checkpoints, Hugging Face caches, raw Banking77 query text, the Banking77
source CSV, and the official Banking77 test split are intentionally excluded.

These artifacts are development evidence, not confirmatory results.
